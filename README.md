# 📊 Sales Dashboard

An interactive Sales Dashboard created using Microsoft Excel as part of my DEPI Data Analysis journey.

## 📌 Project Overview

This project focuses on analyzing sales data and transforming it into meaningful business insights using Excel.

The project includes data cleaning and preparation, calculated fields, KPI analysis, Pivot Tables, and interactive visualizations to understand sales performance.

## 🛠️ Tools & Techniques

- Microsoft Excel
- Data Cleaning & Preparation
- Pivot Tables
- KPI Analysis
- Data Visualization
- Sales Performance Analysis

## 📈 Dashboard Insights

The dashboard provides insights into:

- Total Revenue
- Average Revenue
- Total Orders
- Total Quantity Sold
- Revenue by Region
- Revenue by Product Category
- Top 5 Products
- Overall Sales Performance

## 📂 Project Structure

- `Dashboard_.xlsx` – Contains the complete dashboard, data, KPIs, Pivot Tables, and calculations.

## 🎯 Objective

The main objective of this project is to practice data analysis using Excel and turn raw sales data into clear and useful insights that can support data-driven decision-making.
